# Gopeed(Fluent)

> 基於 [Gopeed](https://github.com/GopeedLab/gopeed) 的非官方分支，提供 Fluent 風格桌面介面。

## 分支特性

- Fluent 風格桌面導覽與視窗控制
- Windows x64、Linux amd64、macOS 發布建置
- 擴充市集與更新檢查直連網路
- Tracker 設定與目前後端 `bt` 協定設定對齊
- 擴充清單狀態響應式更新，包含忙碌、更新與分頁指示
- 設定與視窗縮放狀態保留
