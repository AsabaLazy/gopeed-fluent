# Gopeed(Fluent)

> 基于 [Gopeed](https://github.com/GopeedLab/gopeed) 的非官方分支，提供 Fluent 风格桌面界面。

## 分支特性

- Fluent 风格桌面导航与窗口控制
- Windows x64、Linux amd64、macOS 发布构建
- 扩展市场与更新检查直连网络
- Tracker 设置与当前后端 `bt` 协议配置对齐
- 扩展列表状态响应式更新，包含忙碌、更新与分页指示
- 设置与窗口缩放状态保留
