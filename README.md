# Gopeed(Fluent)

> Unofficial fork of [Gopeed](https://github.com/GopeedLab/gopeed) with a Fluent-style desktop UI.

## Branch features

- Fluent-style desktop navigation and window controls
- Windows x64, Linux amd64, and macOS release builds
- Direct extension-store and update-check networking
- Tracker settings aligned with the current backend `bt` protocol config
- Reactive extension-list state, including busy, update, and pagination indicators
- State-preserving settings and window-resize handling
