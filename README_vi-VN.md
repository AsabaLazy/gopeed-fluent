# Gopeed(Fluent)

> Fork không chính thức của [Gopeed](https://github.com/GopeedLab/gopeed), cung cấp giao diện desktop phong cách Fluent.

## Tính năng của fork

- Điều hướng desktop và điều khiển cửa sổ phong cách Fluent
- Bản build phát hành cho Windows x64, Linux amd64, macOS
- Kết nối trực tiếp đến extension store và kiểm tra cập nhật
- Cấu hình Tracker đồng bộ với cấu hình protocol `bt` của backend hiện tại
- Trạng thái danh sách extension cập nhật theo thời gian thực, gồm busy, update và phân trang
- Giữ trạng thái cài đặt và thay đổi kích thước cửa sổ
