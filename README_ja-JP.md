# Gopeed(Fluent)

> [Gopeed](https://github.com/GopeedLab/gopeed) の非公式 fork で、Fluent 風のデスクトップ UI を提供します。

## ブランチの特徴

- Fluent 風のデスクトップナビゲーションとウィンドウ操作
- Windows x64、Linux amd64、macOS 向けリリースビルド
- 拡張ストアと更新チェックの直接ネットワーク接続
- 現行バックエンドの `bt` プロトコル設定に合わせた Tracker 設定
- 拡張一覧の状態をリアクティブに更新（busy、更新、ページング）
- 設定とウィンドウリサイズの状態保持
